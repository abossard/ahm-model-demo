# Storyboard icons

The 21 Azure architecture icons the video storyboard needs, so the scene guides link to something
that is actually in the repo.

- **Source:** [Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/),
  package `Azure_Public_Service_Icons_V24`
- Filenames are unchanged from the official package, so each traces back to its origin.
- The full 714-icon set is not committed. Download it into `assets/azure-icons/`, which is
  gitignored, if you need something that isn't here.
