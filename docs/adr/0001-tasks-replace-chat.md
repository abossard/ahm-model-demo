# Tasks replace the chat copilot

Agent work starts as a Task (Review, Explain or Design) from a form with a type, a target and an optional instruction, and ends in a structured result such as a health model diff. The CopilotKit chat in `src/agent-web` and the web app's `/agent` proxy are removed. The old copilot always read the default model and shared no context with the graph, and keeping it next to tasks would mean two agent stacks. Follow-ups are new tasks in the same Session, not chat messages. CopilotKit was reconsidered as the UI kit for the Session workspace and rejected: its supported production setup needs a Node runtime, which is a second container, its direct-to-agent mode is part of a paid tier, and its run streams belong to the browser that started them, while a Session's timeline must replay for every visitor. The workspace is built from Fluent UI v9 components over the web app's own event stream.
